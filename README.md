# 🎟️ Online Event Management System

A full-stack **Online Event Management and Ticket Reservation System**.  
The **frontend UI** is built using **HTML, CSS, and JavaScript**, while the **backend** is developed using **Java Servlets**, **JDBC**, and **MySQL**, and runs on **Apache Tomcat 9**.

This system allows users to view events and book tickets, while admins can create and manage events.

---

## 🛠️ Technologies Used

### Frontend (UI)
- HTML5
- CSS3
- JavaScript (Vanilla JS)

### Backend
- Java Servlets
- JDBC
- Maven

### Database
- MySQL 8.0+

### Server
- Apache Tomcat 9

---

## 📋 Prerequisites

Before running the project, make sure you have the following installed:

- **JDK 8 or higher**
- **Apache Maven 3.6+**
- **MySQL Server 8.0+**
- **Apache Tomcat 9.0+**
- A browser (Chrome, Edge, Firefox, etc.)
